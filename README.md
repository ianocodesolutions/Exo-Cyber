# Livre d'or - Atelier Studeria

Petite application web : les visiteurs laissent un message et peuvent s'inscrire pour recevoir les prochaines dates d'atelier. Un espace administrateur permet de consulter les inscrits et de supprimer des messages.

Les données sont stockées dans une base Supabase.

## Lancer l'application

Double-cliquez sur `index.html` : la page s'ouvre dans votre navigateur. Aucune installation n'est nécessaire.

## Votre mission

Le client veut mettre ce site en ligne la semaine prochaine. Avant cela, vous devez vérifier qu'il est sécurisé.

Ouvrez ce dossier dans l'onglet Code de Claude Desktop, puis suivez les consignes de votre formateur.

Règle du jeu : vous lisez et analysez le code, vous ne le modifiez pas.
